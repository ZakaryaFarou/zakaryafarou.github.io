# Zakarya Farou — Academic Website

First working version of a GitHub Pages-compatible academic website.

## Design direction
Data-centric, research-oriented, minimal, sophisticated and technically credible. The site is deliberately not a clone of another academic website.

## Stack
Plain HTML/CSS/JS + JSON data. This can be deployed directly to GitHub Pages and later migrated to Hugo without redesigning the content model.

## Current pages
- Home
- Research
- Publications
- Projects
- About
- Collaborate

## Verification note
The initial publication dataset is based on publicly available ELTE, Springer, CEUR, DBLP, OpenReview and bibliographic records checked in September 2026. It is a working verified corpus, not yet a claim that every MTMT/Google Scholar item has been exhaustively reconciled.
